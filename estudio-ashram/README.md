# Estudio Ashram

Prototipo local para una app privada de creacion y organizacion de contenido.

## Idea

- Carpetas simples.
- Notas locales.
- Guiones para teleprompter.
- Capitulos para EPUB.
- Respaldo local.
- Boton de subir a plataforma.

## Probar

```powershell
python -m http.server 5210 --bind 127.0.0.1
```

Abrir:

```text
http://127.0.0.1:5210
```
