# Editor Video Ashram

Prototipo responsive para preparar videos verticales 9:16 y horizontales 16:9 con identidad del Ashram.

## Probar local

```powershell
python -m http.server 5200 --bind 127.0.0.1
```

Abrir:

```text
http://127.0.0.1:5200
```

## Estado

Esta primera version permite elegir formato, cargar un video local, previsualizarlo, aplicar titulo/subtitulo/logo y usar plantillas iniciales.

El siguiente paso es conectar exportacion real a MP4 con FFmpeg.
